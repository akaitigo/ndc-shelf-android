# Roadmap

ロードマップはIssue作成時のたたき台です。ユーザーの蔵書データをロックインしないこと、スキャンの速さを落とさないことを優先します。

## v0.1 — Local First

- 連続ISBNスキャン
- NDL Searchによる書誌・NDC取得
- 端末内DB
- 蔵書検索
- 棚位置・読書状態
- NDC類別マップ
- Unit Test / Lint / GitHub Actions

## v0.2 — Own Your Data

- [x] JSON / CSVエクスポート
- [x] 検証・プレビュー・原子反映を行う共通インポート基盤
- [x] バージョン付きJSONインポート
- [x] CSVインポート
- [x] 書誌・分類の手動補正
- [x] 所有コピー単位の削除と取り消し
- [x] データベースのバックアップと復元
- [x] 移行・バックアップ操作を集約したデータ管理画面
- [x] アプリ内のライセンス・プライバシー表示
- [ ] v0.1.2更新・複数DocumentProvider・復元を含む実機リリースゲート

## v0.3 — Physical Library

- [x] 部屋・本棚・段の階層管理
- [x] 棚の並び順と「戻す場所」表示
- 書店モード（持っている / 欲しい / 予約済み）
- 連続スキャンのセッション履歴と取り消し

## v0.4 — Series

- 漫画・ライトノベルのシリーズ統合
- 所有巻、欠巻、最新巻
- 版違い・文庫化・新装版の扱い
- 発売予定のウォッチ（任意）

## v1.0 — Personal Librarian

- 任意の同期バックエンド
- 自然文検索
- 読書傾向と再発見
- AI司書（外部送信範囲を明示したオプトイン）
- アクセシビリティと多言語対応

## Non-goals

- 広告ベースの収益化
- ユーザーの同意なしのクラウド同期
- データを独自形式に閉じ込めること
