# v0.4.0 リリースノート（候補）

## 概要

v0.4.0では、端末内の蔵書をシリーズと巻として整理できます。タイトルからの提案は候補として表示し、利用者が確認するまで確定済みの所属にはしません。同じ作品の文庫版・新装版なども、書誌や所蔵コピーを変更せず関連付けと解除ができます。

## 主な変更

- 整数巻、上下巻、外伝、合本を区別したシリーズ管理
- 候補の個別編集、一括確定、既存シリーズへの追加、所属解除
- 文庫版・新装版などの可逆な作品関連付け
- 明示的に有効化したシリーズだけを対象にしたNDL Searchの新刊書誌候補確認
- シリーズ、作品関連、新刊候補を含む完全バックアップ形式12

## データと通信

シリーズの表示と編集は端末内データだけで動作します。新刊候補の定期確認はシリーズごとに初期OFFです。有効化した場合だけ、対象シリーズ名と検索開始年をNDL SearchへHTTPSで送ります。成功後は7日間隔を空け、通信障害時はWorkManagerが一時的に再試行します。蔵書、読書状態、置き場所、購入状態、他のシリーズは送信しません。

書誌候補の出典は国立国会図書館サーチです。候補は発売予定、発売日、網羅性、在庫を保証せず、確定済みのシリーズ所属へ自動昇格しません。詳細は[プライバシー方針](../../PRIVACY.md)と[NDL通信境界](../NETWORK_BOUNDARY.md)を参照してください。

## 更新と互換性

v0.3.0（Room v7）からv0.4.0（Room v11）への明示的Migrationで、Work、Edition、OwnedCopy、部屋、本棚、段、読書状態、棚順を保持します。更新だけではシリーズ、作品グループ、監視設定、新刊候補を推測生成しません。完全バックアップは形式12へ更新され、古い対応形式は安全な既定値で読み込みます。

## 既知の制約

- 欠巻候補は利用者が確定した本編Membershipだけから算出し、未登録番号の刊行を断定しません。
- 最新所有巻は保存済みの並び順で最後の所有巻を示し、外部の最新刊を意味しません。
- シリーズ統合、クラウド同期、複数端末同期は対象外です。
- NDLの利用条件確認・事前連絡、同一署名v0.3 APKからの更新試験、通知・再起動・オフラインの物理実機試験が完了するまで配布しません。

公開可否と未完了ゲートは[リリースチェックリスト](V0.4_RELEASE_CHECKLIST.md)、障害時の対応は[ロールバック手順](V0.4_ROLLBACK.md)を参照してください。
