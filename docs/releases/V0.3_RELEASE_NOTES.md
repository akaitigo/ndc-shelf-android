# v0.3.0 Release Notes（Draft）

## 物理本棚を日常運用できるようになりました

- 部屋・本棚・段で置き場所を管理し、段内の並び順と戻す位置を確認できます。
- 同じ版を複数冊登録し、copyごとに表示名、置き場所、読書状態を管理できます。
- 書店モードで所有冊数、欲しい、予約済みを確認し、購入時に本棚へ移せます。
- 連続scanの試行履歴を確認し、未編集の追加分を個別またはsession単位で取り消せます。
- トーチ、pinch zoom、tap focus、成功feedbackとcamera権限案内を追加しました。
- NDL未収録の本をofflineで手動登録し、後から差分確認付きで照合できます。
- 版の書誌情報と複数の所有copyを分けて確認できる詳細画面を追加しました。
- 大規模蔵書の検索、読書状態filter、複数の並べ替えをRoom側で処理します。

## データとprivacy

蔵書、barcode認識、購入状態、scan履歴は端末内に保存します。NDL Searchへは書誌取得時のISBNだけを送信します。新しい権限や外部送信先は追加していません。更新時は既存の書誌、場所、読書状態、追加時刻を保持します。

## 既知の制約

- camera品質、100件連続scan、5,000冊性能、TalkBackは端末差があるため、[release checklist](V0.3_RELEASE_CHECKLIST.md)の実機証跡完了まで本notesはDraftです。
- Androidの通常仕様では低いversionCodeへdowngradeできません。問題時は[rollback手順](V0.3_ROLLBACK.md)に従い、配布停止と修正版へのroll forwardを行います。
