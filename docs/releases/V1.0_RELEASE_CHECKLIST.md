## 判定

**状態: BLOCKED（実機・配布証跡待ち）**

Issue #55の正本。自動ゲートはPull Requestごとに実行する。手動ゲートを全て証跡付きで
完了するまでtag作成と配布を行わない。データ損失、無断通信、鍵管理不備、重大な
アクセシビリティ障害が一つでも残る場合はリリースを停止してIssue化する。合格基準を
都合よく緩和しない。期限付きの例外だけを[例外](#例外)へ記録する。

## 自動ゲート

Pull Requestごとに`android.yml`が実行する。release candidateのrun URLを[証跡](#証跡)へ記録する。

- [ ] `verifyBackupPolicy`: OS backup／端末間転送ruleをfail closedで検証する。
- [ ] `verifyV*ReleaseConfiguration`: install可能なv1.0識別子を検証する（リリース時に更新）。
- [ ] `verifyLicenseReport` / `:app:cyclonedxDirectBom`: release依存・ライセンス本文・SBOMを生成する。
- [ ] `verifyRoborazziDebug`: 全unit testと主要画面のライト／ダーク／大文字スクリーンショット回帰。
- [ ] `lintDebug` / `assembleDebug` / `assembleDebugAndroidTest`。
- [ ] `git diff --exit-code -- app/schemas`: Room schema fixtureの未commit差分がない。
- [ ] `android-test` (API 26／29／35): instrumentation全件。
- [ ] `update-install`: v0.1.2からの更新インストールでアプリdataが保持され、更新後に起動する。
- [ ] `LegacyDatabaseUpgradeInstrumentationTest`: v1のDBが現行schemaで全項目を保持して開ける。
- [ ] `osv-scan`: 既知脆弱性ゼロ、または期限付き例外のみ。
- [ ] `.github/scripts/verify-osv-exceptions.sh` / `verify-action-pins.sh` / `verify-release-tag.sh`。
- [ ] `benchmark.yml`（workflow_dispatch）: 起動・スクロール・AABサイズの性能予算。
