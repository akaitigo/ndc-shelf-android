## 判定

**状態: BLOCKED（実機・配布証跡待ち）**

最終更新: 2026-08-11。ADR 0009の「`ai`フレーバーを配布しない」決定を反映し、
配布しない成果物の実機検証をv1.0のゲートから外した（[配布を再開する場合の前提条件](#aiフレーバーの配布を再開する場合の前提条件)）。
デバイスを要しない項目は実測・自動テスト化して埋めた。

**残る未完了は実機・署名鍵・v1.0版数決定を要する項目だけになった。**

- 実機: 受け入れ条件1の署名付きAPK更新経路、2の実機2台同期と実DocumentProvider、3の通信監査、
  5のTalkBack・日英E2E・tablet・通知アイコン、6の性能実測、8のサイドロードとロールバック演習
- 署名鍵: 4-1の両フレーバー署名証明書SHA-256の一致判定（`release.yml`が自動判定）
- 版数決定: `verifyV06ReleaseConfiguration`のv1.0向け改名と期待値更新。`versionCode`・
  `versionName`のbumpを伴うため、v1.0 RCを切る判断とセットで行う

Issue #55の正本。自動ゲートはPull Requestごとに実行する。手動ゲートを全て証跡付きで
完了するまでtag作成と配布を行わない。データ損失、無断通信、鍵管理不備、重大な
アクセシビリティ障害が一つでも残る場合はリリースを停止してIssue化する。合格基準を
都合よく緩和しない。期限付きの例外だけを[例外](#例外)へ記録する。

## `ai`フレーバーの配布を再開する場合の前提条件

**v1.0のリリースゲートではない。** ADR 0009で配布しないと決めたため、以下はGitHub Releasesへ
`-ai.apk`を添付する判断をした時点で初めて必要になる。再設計の方針は
`docs/ON_DEVICE_LLM_FINDINGS.md` を正本とする。

配布を再開する場合は、代表端末2系統以上で以下を確認する。

- [ ] モデル格納容量・peak RSS・初期化時間・first-token latency・生成速度を測定し、
      `docs/PERFORMANCE_BUDGETS.md` の実行時予算表へ記入した
- [ ] 15分連続利用時の熱状態（`dumpsys thermalservice`）と電池消費（`dumpsys batterystats`）を測定した
- [ ] 日本語の「次に読む本」「テーマ別整理」「蔵書概観」の3ユースケースで、
      根拠となる参照本と不確実性を含む提案が返ることを確認した（品質の主観評価も記録する）
- [ ] 推論中の通信監査（HTTPS proxyまたは端末のネットワークログ）で、質問文・蔵書項目・prompt・回答・
      推論テレメトリの送信がゼロであることを確認した
- [ ] モデル取得の通信監査で、送信先が `huggingface.co` と `hf.co` 配下のCDNのみ・
      リダイレクト追従が1回だけ・cookie/認証headerなしを確認した
- [ ] `ConsentPurpose.MODEL_DOWNLOAD` に同意していない状態で取得が一度も始まらないことを確認した
- [ ] checksum改変ファイル、サイズ不一致ファイル、取得中断の3ケースでモデルが有効化されず、
      直前の検証済みモデルが保持されることを確認した
- [ ] 書名・著者・タグ・メモへprompt injection文字列を入れた蔵書で、system instruction・出力schema・
      許可refの境界を越えないことを確認した
- [ ] 非対応端末（API 23／armeabi-v7a／低RAM／空き容量不足）で取得も起動も行われず、
      理由と縮退導線が表示される
- [ ] 画面離脱・同意撤回・background移行で推論と取得がキャンセルされ、ANR・クラッシュが発生しない
- [ ] 相談の前後で蔵書データが不変（export差分ゼロ）であることを確認した
- [ ] モデルとモデル由来cacheをアプリ内から全削除でき、削除後に断片が残らないことを確認した
- [ ] 台帳から定義を外す（またはruntimeを `UnavailableLlmRuntime` へ戻す）だけで
      ヒューリスティックへ戻せることを確認した
- [ ] リリースノートへ2つのAPKの違い、アプリIDが異なること、**データを共有しないため乗り換えには
      エクスポート→インポートが必要**であることを明記した
- [ ] リリースノートへモデルのライセンス（Apache-2.0）・サイズ・取得先と、
      日本語品質を保証しない旨を明記した
