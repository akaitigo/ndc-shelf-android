# v0.3 物理本棚リリースチェックリスト

## 判定

**状態: BLOCKED（v0.2公開、実機証跡待ち）**

v0.3は`versionCode = 5`、`versionName = "0.3.0"`とする。v0.3の機能PR #72から#80は依存順にmerge済みだが、先にIssue #19のv0.2 release gateを完了する。以下の自動・実機ゲートが全て成功するまでtag作成、署名、配布を行わない。データ欠落、棚順の破損、取消不能、匿名でないテストデータ、アクセシビリティ上の操作不能が1件でもあればreleaseを停止してIssue化する。

## 対象

- 更新元: Issue #19完了後に公開するv0.2.0 release commit（現時点ではtag未作成。検証時にSHAを記録）
- 更新先: v0.3.0 release candidate commit（`versionCode = 5`、検証時にSHAを記録）
- DB: v0.2のv1からv0.3のv7まで
- 自動fixture: `V03PhysicalLibraryReleaseTest`の匿名データと1,000／5,000／20,000冊の合成検索データ
- 禁止データ: 実在する個人蔵書、氏名、自宅の置き場所、private URI、撮影した実蔵書のバーコード画像

## 実機ゲート

端末名、Android版、DocumentProvider、release candidate SHA、実施者、日時、匿名証跡の保存先を[証跡](#証跡)へ記録する。最低2系統の端末で確認し、1台はAPI 28〜30、1台は最新targetSdk付近とする。

### v0.2からの更新

- [ ] v0.2.0 APKを同じ署名でinstallし、匿名の3冊へ書誌、旧location、読書状態、追加時刻を設定する。
- [ ] app dataを消さずv0.3.0候補を`adb install -r`し、全項目、件数、旧locationが保持される。
- [ ] 同一ISBNを3冊に増やし、表示名と状態がcopy単位で保持される。
- [ ] 部屋・本棚・段へ配置し、左右移動、編集取消、削除復元後も再起動で順序が保持される。

### 書店・scan・camera

- [ ] onlineで未所蔵ISBNを欲しい、予約済み、購入済みへ遷移し、購入時にcopyが1冊だけ増える。
- [ ] 機内モードで保存済み購入状態を表示・変更でき、未取得ISBNはoffline表示となり既存データを変えない。
- [ ] [scan実機手順](../SCAN_DEVICE_TESTING.md)で暗所・小型バーコードを含む100件をscanする。
- [ ] 100件に成功、重複、無効、未収録、通信失敗を含め、件数と履歴が一致する。
- [ ] 未編集の追加分は一括取消でき、編集済みcopyを含む場合は全体を変更せず競合表示になる。

### 性能・アクセシビリティ

- [ ] [検索性能予算](../LIBRARY_SEARCH_PERFORMANCE.md)の5,000冊条件をrelease相当buildの基準端末で満たす。
- [ ] 初期一覧p95 700ms以下、検索p95 250ms以下、連続入力時のstale結果なし、追加heap 24MiB以下を記録する。
- [ ] TalkBackで下部navigation、本棚検索、copy選択、棚移動、書店状態、scan取消を順番に操作できる。
- [ ] font scale 200%、表示サイズ最大、light/dark、高コントラスト相当で主要操作が欠けない。
- [ ] camera権限拒否・恒久拒否から設定導線へ到達し、カメラなしでも本棚と手動登録を利用できる。

## Release操作

1. Issue #19を完了してv0.2.0を公開し、そのrelease commitとartifactを更新元として固定する。
2. v0.3機能PR #72から#80が依存順にmerge済みで、main上のCI成功とlinear historyを確認する。
3. 実機ゲートと証跡を埋め、`BLOCKED`を`READY`へ変更するPRを作成する。
4. `CHANGELOG.md`の`Unreleased`を日付付き`0.3.0`へ確定し、release notesのSHAと一致させる。
5. 同じcommitから署名済みAAB/APKを作り、SHA-256、署名証明書fingerprint、mapping、SBOMを保管する。
6. tag `v0.3.0`をrelease commitへ付け、段階配布する。crash、ANR、data loss、scan失敗率を監視する。
