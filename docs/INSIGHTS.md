# 読書傾向と再発見（Insights）

分析タブが提示する指標の定義・データ源・限界、除外操作、表現ガイドラインの正本。実装は `domain/insights/LibraryInsightsCalculator`（純粋関数）と `InsightsViewModel`、UIは `ui/screens/InsightsScreen` にある。

## 原則

- **端末内のみ**: 集計はすべて端末内で行い、外部送信しない。分析のための新しい通信・SDK・識別子は追加しない。画面にもその旨を明示する。
- **説明可能**: 候補には必ず「選ばれた理由」を添える。理由は保存済みの事実（追加日、読書状態、読了日）だけから導出し、推測を混ぜない。
- **断定しない**: 履歴が閾値未満の指標はグラフを表示せず、どのデータが何件必要かを説明する。
- **利用者が制御できる**: 候補ごとの「対象外にする」と、除外リストを全消去する「分析リセット」を提供する。

## 指標

### 積読期間

| 項目 | 内容 |
| --- | --- |
| 定義 | 未読（`ReadingStatus.UNREAD`）の所有コピーについて、`addedAt`（登録日時）から現在までの経過日数 |
| データ源 | `owned_copies.addedAt` と `readingStatus` |
| 表示 | 経過日数が長い順に上位5冊。未読の総数は除外に関係なく全数を表示する |
| 限界 | 経過日数は86,400秒を1日とする端末時刻ベースの近似で、暦日・タイムゾーンの境界を考慮しない。インポートした本は`addedAt`がインポート実行時刻に集中するため「積読期間」が実際より短く見える。時計が巻き戻っていても負の日数は表示しない（0日へ丸める） |

### NDC類の傾向

| 項目 | 内容 |
| --- | --- |
| 定義 | NDCコード第1桁（類）ごとの冊数と、分類済み冊数に対する比率 |
| データ源 | `owned_copies` に紐づくEditionの `ndcCode` |
| 表示 | 類別の冊数・比率・バー。未分類の冊数を別掲する |
| 限界 | 第1桁だけを使うため綱目以下の偏りは表現しない。NDC新旧版の差異は区別しない |

### 読了推移

| 項目 | 内容 |
| --- | --- |
| 定義 | 読了（FINISHED）セッションの読了日（`finishedDay`）を月ごとに数えた直近12か月の推移 |
| データ源 | `reading_sessions`（Room v14、#56）。読了状況と読了日だけを使い、評価・メモは集計に使わない |
| 表示 | 月別の棒グラフ（冊数を数値でも併記）。月精度以上の読了日を持つセッションが3件未満の場合はグラフを表示せず、必要なデータを説明する |
| 限界 | 部分日付のうち年のみ（例: "2026"）はどの月にも割り当てられないため件数として別掲する。読了日なし・表示期間外も同様に別掲する。同期による重複履歴に備え、同一セッションIDは1回だけ数える。コピー削除時は履歴もCASCADE削除されるため、削除済みの本の読了は推移に残らない |

### ランダム再発見

| 項目 | 内容 |
| --- | --- |
| 定義 | 除外を反映した蔵書から、seed付き乱数で無作為に選んだ最大3冊 |
| データ源 | `owned_copies` と `reading_sessions`（理由の導出のみ） |
| 表示 | 候補ごとに理由を必ず添える。理由は読書状態に応じて「N日前に追加され、まだ読み始めていません」「読みかけのまま棚にあります」「YYYY-MM-DDに読了した本です。再読の候補としてどうぞ」のいずれか |
| 限界 | 無作為抽出であり嗜好の推定ではない。seedは画面のViewModel生存期間中は固定し、表示のたびに候補が入れ替わらないようにする |

## 履歴不足時の扱い

- 読了推移: 月精度以上の読了日を持つ読了セッションが3件（`LibraryInsightsCalculator.DEFAULT_MINIMUM_TREND_SESSIONS`）未満なら、空グラフを出さずに「読了日のある読書履歴が3件必要（現在N件）」と記録方法を案内する。
- NDC類・再発見: 対象データが0件のときは空表示ではなく、本の登録や分析リセットで表示できることを説明する。

## 除外と分析リセット

- 「対象外にする」はコピーIDを端末内のSharedPreferences（`insights-exclusions`）へ保存する。Roomのschema変更（migration）を伴わない表示設定であり、蔵書・読書履歴・同期・エクスポート・完全バックアップへ影響しない。
- 除外は積読・再発見の**候補の提示だけ**から外す。総数・NDC分布・読了推移などの集計値からは除外せず、数を偽らない。
- 「分析リセット」は除外リストを全消去し、すべての本を候補へ戻す。実行前に確認ダイアログを表示する。
- 肥大化を防ぐため除外は1,000件を上限とし、上限到達後の追加は受け付けない（リセットで解消できる）。削除済みの本の除外エントリは候補側で自然に無視され、除外数の表示は現存する本だけを数える。

## 表現ガイドライン

推薦が偏りや罪悪感を生むリスク（Issue #41）への対応:

- 事実の説明に限る（「420日前に追加され、まだ読み始めていません」）。評価・催促・比較（「読むべき」「たまっています」「平均より少ない」）を使わない。
- 積読セクションには「読む・手放す・そのまま置いておく、どれを選んでも大丈夫」という中立の説明を添える。
- 未読冊数・読了冊数は目標や達成率として表示しない。

## アクセシビリティ（TalkBack）

- 読了推移の棒グラフは冊数を数値テキストで併記し、各棒に「YYYY年M月の読了はN冊」のcontentDescriptionを付ける。色・高さだけに情報を依存しない。
- NDC類の行は比率・冊数をテキスト併記し、行全体へ「digit 類名、N冊、分類済みのP%」の読み上げ説明を付ける。
- セクション見出しは `semantics { heading() }`、装飾アイコンは `contentDescription = null`、候補の除外ボタンには書名入りの説明を付ける。
