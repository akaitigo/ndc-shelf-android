# ストア掲載情報

この文書はストア掲載時に使用する原稿です。公開前に、対象ストアの最新の定義と実際のリリース成果物を照合してください。

## プライバシー説明

NDC Shelfはアカウント、広告、開発者独自のアクセス解析・クラッシュ解析を使用しません。カメラ画像とバーコード認識は端末内で処理し、蔵書は端末内に保存します。ISBN検索時はISBNだけを国立国会図書館サーチへ送信します。シリーズの定期確認を明示的に有効にした場合だけ、対象シリーズ名と検索開始年を最大週1回送信します。読書状態、置き場所、購入予定、他の蔵書は送りません。表紙は同サービスのHTTPS thumbnailだけから取得し、最大50MiBキャッシュします。ML Kitは認識内容をGoogleへ送りませんが、診断・利用分析情報を収集します。

利用者が作成するJSON、CSV、完全バックアップは指定した保存先にだけ書き出され、アプリが独自にアップロードすることはありません。Androidのクラウドバックアップから全アプリデータを除外しています。Android 9以降の端末間転送ではRoomデータベースだけを対象にし、Android 8.1以前ではOS移行も対象外です。

詳細: `PRIVACY.md`

## データセーフティ申告時の確認事項

- ISBNのNDL Searchへの送信は、利用者が登録操作をしたときだけ発生し、書誌情報取得というアプリの中核機能に使用する。
- シリーズ名の送信はシリーズごとの初期OFF設定を利用者が有効にした場合だけ、最大週1回発生する。
- 表紙画像の取得先はNDL Searchに限定し、別hostへのredirectを追従しない。URL path内のISBNと通常のHTTPS通信情報が同サービスへ伝わり得る。
- 表紙画像は最大50MiBの再生成可能な端末キャッシュへ保存し、バックアップ・export対象にしない。
- 開発者運営のサーバー、広告SDK、開発者独自の解析・クラッシュ解析SDKへのデータ送信はない。
- ML Kit SDKは端末・アプリ情報、インストール単位の識別子、性能、API設定、入出力サイズ、機能バージョン、利用イベント、エラーコード等をGoogleへ送信する。Googleの最新公式開示と使用SDK版を再確認する。
- AndroidのOSクラウドバックアップは全データを除外する。API 28以降の端末間転送だけRoomデータベースを対象にする。
- カメラ画像は端末外へ送信せず、保存もしない。
- ストアの「収集」「共有」「一時的処理」の最新定義に照らして、ISBN送信、ML Kitメトリクス、OS管理バックアップの回答を公開直前に再判定する。
